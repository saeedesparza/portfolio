# Saeed Esparza — Portfolio

Personal portfolio site for TCSS 490 (Autumn 2026). Front-end only (HTML/CSS), hosted on GitHub Pages.

- Live site: `https://saeedesparza.github.io/portfolio/` (after Pages is enabled)
- Dev log: [devlog.md](devlog.md)

## Structure

- `index.html` — page markup, including the five artifact cards
- `styles.css` — "field notes" visual theme
- `devlog.md` — log of AI interactions and changes made during development

## Local preview

Just open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```

## Deploying

1. Push this repo to GitHub as `portfolio` under `saeedesparza`.
2. In the repo settings, enable **GitHub Pages** → source: `main` branch, root folder.
3. Site will be live at `https://saeedesparza.github.io/portfolio/`.
